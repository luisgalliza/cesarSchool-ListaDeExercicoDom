# 🧩 Exercício de JavaScript — Eventos e Interatividade

Este repositório contém uma atividade acadêmica desenvolvida na **CESAR School**, utilizando **HTML e JavaScript**, com foco na **interatividade da página** por meio de eventos.

## ✨ Objetivo do Exercício
O objetivo desta atividade foi praticar conceitos fundamentais de **JavaScript aplicado ao front-end**, especialmente:
- Captura de eventos do usuário;
- Interação com elementos da página;
- Alteração de conteúdo de forma dinâmica;
- Integração entre HTML e JavaScript.

## ⚙️ Sobre o Exercício
O exercício consiste em uma página simples onde ações do usuário (como cliques ou interações com botões) disparam funções em **JavaScript**, que modificam o comportamento ou o conteúdo exibido na tela.

O foco do projeto está na **lógica e funcionamento do JavaScript**, com HTML servindo apenas como base estrutural.

## 🛠️ Tecnologias Utilizadas
- HTML5  
- JavaScript (ES6+)  

## 🎓 Contexto Acadêmico
Atividade prática realizada na **CESAR School**, voltada para o aprendizado de **eventos, funções e manipulação básica do DOM**, consolidando conhecimentos iniciais de programação web.
